# Security policy

Please report a suspected vulnerability privately to the repository owner instead of opening a public issue with exploit details or user data.

Supported code is the latest commit on the default branch. Reports should include affected version, reproduction steps, impact, and a minimal proof of concept with synthetic data.

The project has no authentication boundary and is not intended to store real candidate data. Deployers are responsible for HTTPS, dependency updates, hosting controls, and any security obligations introduced by added analytics or persistence.
