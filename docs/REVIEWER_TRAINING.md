# Reviewer training guide

## Purpose

A reviewer checks whether a deterministic concept-coverage score is a useful coaching signal. A reviewer does not certify candidate competence and must not use this application for employment decisions.

## Before reviewing

1. Read the question, expected concepts, submitted answer, calculation, and feedback.
2. Confirm that the result is `scored`; abstained answers display no numeric score, do not affect the average or adaptive difficulty, and cannot be approved as a score.
3. Ignore names, demographic cues, writing style, and other identity proxies. Review only technical evidence relevant to the question.

## Decisions

- **Accept score** when the matched and missed concepts reflect the substance of the answer.
- **Flag correction** when a correct synonym was missed, a substring created a false match, the rubric is incomplete, or the feedback is misleading.

Use a stable reviewer identifier. Notes should state the evidence and proposed rubric change, not a judgment about the person.

## Calibration exercise

Before reviewing real practice sessions, have two reviewers independently review the same ten synthetic answers. Discuss disagreements, update expected concepts, and rerun the counterfactual tests. Recalibrate after any rubric change.

## Escalation

Stop using a question if reviewers repeatedly disagree, if identity-like text changes results, or if the expected concepts do not cover valid approaches. Record the issue and fix the rubric before resuming.
